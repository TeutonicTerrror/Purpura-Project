# AI Use Disclosure -- Required

Every pull request and code contribution to this public repository **must** include an AI disclosure in the PR description.

- **Was AI used?** Yes / No. If no: `AI disclosure: No AI was used.`
- **If yes:** name the tool(s) (Muse, ChatGPT, Cursor, Gemini, etc.) and the files/sections they produced.
- **Human verification:** one line stating how you verified the change in-browser.

PRs without a disclosure will be asked to add one before review. See `.agents/ai-disclosure.md` for the full template.
